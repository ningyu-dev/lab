# 宁雨 · agent 工程实验与学习记录

这个仓库不放产品代码，放**判断记录**。

## 为什么单独建这个仓库

项目的两个目标不同：

1. 做出一个能给工程师用的工具
2. 搞清楚 agent 到底应该怎么开发

第一个目标的产物是代码，第二个目标的产物是**可复用的判断**。第二个目标不占代码位，但如果不单独记，它会散落在对话和 commit message 里，然后消失。

所以这个仓库的每个文件都是同一类：**一个决策 + 它的理由 + 它被推翻的条件。**

## 记什么

- 某个 agent 设计选择为什么成立
- 某个失败模式是怎么发现的
- 自主与人工的边界划在哪里，依据是什么
- 可复现性怎么保证，为什么必须保证
- 什么情况下当前设计会失效

## 不记什么

- 进度日志（那是 issue 的事）
- 教程式的 agent 科普（要学去看别人的仓库）
- 没有结论的探索记录（探索写进 commit message 或 issue）

## 核心问题清单

这些是这个仓库要持续回答的问题。答案会变，变了就在这里更新并说明为什么变。

- agent 在哪一步该自主，在哪一步必须停下等人？边界依据是什么？
- 怎么保证同样的输入永远得到同样的输出？
- 失败模式有哪些，怎么设计才能失败得可控？
- 什么该写成确定性代码，什么该交给模型判断？
- agent 做的每个决定，怎么让人能追责？
